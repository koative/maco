# OpenStore

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Confirmed: English-language Astro static site deployed to GitHub Pages under Koative. Folder-based Markdown content powers both website and generated README catalog. No database or account required.

## Users

Mac users discovering useful open-source applications, and contributors adding or improving catalog entries through GitHub.

## Product Purpose

Make open-source macOS software easy to discover, inspect, and contribute to through a beautiful searchable catalog with categories, tags, screenshots, license information, and direct official links.

## Operating Context

Users browse and filter applications, inspect details and screenshots, then visit the official project or download page. Contributors edit one app folder and submit a pull request.

## Capabilities and Constraints

App folders are the source of truth. Metadata is validated. README is generated. Every entry links upstream source and license evidence. Assets retain provenance and upstream rights. Do not equate freeware or source-available software with open source. Research multiple directories rather than importing a single list. Public GitHub repository under koative, incremental commits, description and homepage.

## Brand Commitments

Working name OpenStore, derived from the existing workspace. English UI confirmed. Design execution delegated to Impeccable, directly in working code. The user rejected the initial pastel library design and explicitly chose a dark, sharp, premium showcase with large imagery.

## Evidence on Hand

Starting reference: https://github.com/jeffreyjackson/mac-apps. Further directory and upstream project research in progress. No invented star counts, reviews, endorsements, compatibility promises, or screenshots.

## Product Principles

- One contribution updates every catalog surface.
- Link verifiable evidence beside discovery content.
- Store genuine app imagery with attribution.
- Keep browsing fast, accessible, and independent of a server.
