Docky rebuilds the Dock as a strip you arrange yourself: apps, folders with nested navigation, spacers, dividers and widgets such as calendar, battery, weather or now playing, which can be stacked into a single rotating tile. It can sit alongside the system Dock, mirror it, or replace it.

Beyond the strip it adds a fullscreen searchable launcher, a Command-Tab-style switcher with live window previews, custom app icons, themes and profiles, and scripted actions. It requires macOS 14 or later; downloads come from the project website and GitHub releases.
