Maestro manages a fleet of command-line coding agents such as Claude Code, OpenAI Codex and OpenCode from a single window. Each agent gets its own session and project, and an Auto Run mode works through a written task list, starting each step in a fresh session.

It passes requests through to the agents you already have configured, so their tools, permissions and accounts carry over. Builds for macOS, Windows and Linux are published on GitHub releases, and a Homebrew cask is available.
