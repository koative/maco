KeeWeb reads and writes KeePass `kdbx` files, so it can share a vault with KeePass, KeePassXC and other compatible apps. It runs as a desktop application or as a self-hosted web app, and can open files from cloud storage such as Dropbox.

The latest desktop release, 1.18.7, dates from July 2021, with separate macOS builds for Apple silicon and Intel. Weigh the age of that build when choosing a tool for sensitive credentials.
