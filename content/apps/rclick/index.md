RClick extends the Finder context menu with actions macOS leaves out: create new text, Markdown, Office or iWork documents from templates, copy a full path, open the selection in any app with arguments, toggle hidden files, send via AirDrop, or delete without using the Trash.

Favorite folders can also be pinned to the menu. The actions come from a Finder extension that you enable in System Settings after the first launch. The project lists macOS 15.6 or later.
