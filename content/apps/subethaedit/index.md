SubEthaEdit is a general-purpose text editor for macOS with syntax highlighting for many languages, and it lets several people edit the same document live over a local network or the internet. It has a long history as a commercial app before being released as open source.

Official builds are published on GitHub releases and through the Mac App Store, as linked from the project's website. The most recent release, 5.2.4, has not been followed by newer versions.
