Clave is a desktop workspace for people who keep several AI coding agents busy at once. Claude Code, Codex CLI, Antigravity CLI and Pi sessions, plus ordinary shells, each get their own terminal and can be tiled in splits or a grid, with status dots showing which ones are working, idle or waiting for input.

A built-in git panel covers diffs, history and commits, a file browser works locally or over SFTP, and whole sessions can run on remote hosts via SSH. There is no account or cloud backend. Releases ship a macOS DMG with built-in updates; a Windows installer exists but trails the Mac version.
