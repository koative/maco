Rocket.Chat Desktop wraps the Rocket.Chat web client in an Electron app, with a sidebar listing the servers you have added so several workspaces sit in one window. You need an account on a Rocket.Chat server, whether self-hosted or provided by the vendor.

The desktop app's repository is MIT-licensed; the server is a separate project. The README lists universal macOS builds for macOS 12 or later in DMG, PKG and ZIP form, and the app is also on the Mac App Store and in Homebrew as a cask.
