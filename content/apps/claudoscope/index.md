Claudoscope reads the session files Claude Code and Claude Cowork leave on your Mac and presents them in a menu bar widget and a dashboard. You can browse and replay conversations, compare projects, and review cost and tool-use analytics.

It can also send notifications when sessions need attention, alert on spending, and scan transcripts for leaked credentials. Processing happens locally; the app is only relevant if you already use these Claude tools.
