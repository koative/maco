DNS Easy Switcher puts DNS choices in a menu bar list: presets such as Cloudflare, Quad9 and AdGuard, your own custom servers, or a return to the DNS supplied by your network. It can also run a speed test and flush the DNS cache.

DNS changes can be confirmed with Touch ID, and settings persist between launches. It is a small single-developer utility installed from GitHub releases or the developer's Homebrew tap.
