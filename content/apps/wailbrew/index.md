WailBrew lets you manage Homebrew without the terminal. It lists installed formulae and casks, shows which are outdated, searches for new packages and installs, upgrades or removes them, and also covers taps and background services.

It is built with Wails, Go and React and positions itself as a maintained alternative to the older Cakebrew. Install it with the official Homebrew cask or from GitHub releases.
