Postgres.app packages PostgreSQL servers, command-line tools and common extensions such as PostGIS and pgvector inside one Mac application. Its window lists your local servers so you can create, start and stop them without managing launch scripts, and several PostgreSQL versions can run side by side.

It is aimed at local development rather than production hosting. The project site publishes the current downloads, while older builds and pre-releases remain on GitHub.
