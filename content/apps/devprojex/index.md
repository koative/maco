DevProjex prepares a codebase for sharing with language models. You tick files and folders in a tree, watch a live preview with a token estimate, and copy or export the selection as text, Markdown, JSON, XML, a folder, or a ZIP, with secrets masked along the way.

The same project also ships a terminal workspace, a CLI, and a read-only MCP server for agents. The macOS desktop app is distributed as Apple silicon and Intel app archives on GitHub releases.
