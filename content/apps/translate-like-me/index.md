Translate Like Me replaces the current selection in any app with its translation when you press a shortcut. Each of up to three language pairs gets its own hotkey, the direction is detected automatically, and an optional style description makes the result read the way you write.

Rewrite presets turn rough or dictated notes into a finished message in the same language. The work is done by Claude, ChatGPT or Grok through the provider's official command-line tool and your existing subscription, so one of those has to be installed. It lives only in the menu bar, updates through Sparkle, and the project lists macOS 15 on Apple silicon as the requirement.
