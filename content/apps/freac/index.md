fre:ac converts audio between common formats such as MP3, AAC, Opus and FLAC, and rips audio CDs with metadata lookups, cue sheets and an integrated tag editor. Its multi-threaded engine can encode to several formats in one pass and verify lossless input and output.

The same application runs on Windows, Linux and FreeBSD. Mac builds are published as disk images on GitHub and freac.org, with separate packages for older and newer macOS versions, and a Homebrew cask is also available.
