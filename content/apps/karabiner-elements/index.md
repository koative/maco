Karabiner-Elements changes how keys behave, from straightforward replacements to complex combinations. It helps adapt external keyboards, create more useful modifier keys, and tailor input to repeated tasks.

The project publishes macOS installers and extensive rule documentation. Its EventViewer companion helps inspect key events while configuring mappings.
