OpenTypeless listens while you hold a hotkey and types the result into whatever app is active, using a language model to tidy punctuation and adapt the tone to the app you are in. The same shortcut system covers rewriting selected text, translating, and asking a quick spoken question that returns a short answer.

You can connect your own speech and language providers, including OpenAI-compatible APIs, Deepgram, Groq and local Ollama, with keys stored on the device. The developers also sell optional managed cloud plans for people who would rather not manage keys. Universal macOS disk images are attached to GitHub releases, though not every release includes one; version 1.1.61 was the latest with a Mac build at the time of review.
