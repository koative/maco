ClashX.Meta is MetaCubeX's fork of ClashX, a menu bar client that routes traffic through proxies according to a Clash configuration file. Rules can direct connections by domain, IP range or GeoIP, and the client supports HTTP, SOCKS, Shadowsocks, VMess and Trojan servers.

It is aimed at users who already have proxy servers and a configuration to point it at; it does not provide any service itself. Builds are published as zipped app bundles on the project's GitHub releases.
