Escrcpy wraps scrcpy in a desktop interface for viewing and controlling Android phones and tablets. It manages several devices at once, supports wireless ADB connections, screenshots, app and file management, keyboard mappings and automation scripts.

The device needs USB debugging enabled. Some advanced features come from a separate paid extension that is not part of this repository. Builds for Apple silicon and Intel Macs, along with Windows and Linux, are on the releases page.
