Sqlectron is a deliberately simple SQL client: save connections, browse databases and tables, run queries and read the results. It covers PostgreSQL, Redshift, MySQL, MariaDB, Microsoft SQL Server, SQLite and, with some limitations, Cassandra.

Saved servers live in a plain configuration file that can be edited or shared. The repository was formerly named sqlectron-gui; macOS DMGs are published with each release and through the `sqlectron` Homebrew cask.
