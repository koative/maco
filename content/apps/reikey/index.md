ReiKey scans for keyboard event taps and helps reveal applications listening to keyboard activity. This is useful when reviewing input-related permissions and unfamiliar background software.

Keyboard utilities can create legitimate event taps too. Treat the results as evidence to investigate rather than automatically labeling every listener as a keylogger.
