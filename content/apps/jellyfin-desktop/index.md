Jellyfin Desktop connects a Mac to a Jellyfin media server. It combines the Jellyfin interface with a desktop playback environment for a personal media library.

A Jellyfin server and media library are required separately. Upstream releases include macOS packages, sometimes under the earlier Jellyfin Media Player name.
