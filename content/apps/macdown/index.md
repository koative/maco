MacDown shows Markdown source on one side and a rendered preview on the other, updating as you type. It offers editor themes, preview styles, code highlighting and options for Markdown extensions such as tables and fenced code.

The latest release dates from 2020 and development has stalled since, so newer macOS versions may expose rough edges. Third-party components carry their own notices in the repository's LICENSE directory.
