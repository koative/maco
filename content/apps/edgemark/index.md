EdgeMark keeps a full-height notes panel parked against the left or right edge of the screen. Pushing the pointer to that edge, or pressing a global shortcut, slides it over whatever app is in front; it can be pinned open while you copy text back and forth, and it follows you across Spaces and full-screen apps.

Notes are ordinary `.md` files in a folder you choose, organized with nested folders, Finder-style colour tags and search, and edited in a live-formatted Markdown editor with task lists, tables, pasted images and LaTeX. Releases offer separate Apple silicon and Intel DMGs plus a cask in the developer's own Homebrew tap; the builds are unsigned, so the README explains how to clear the quarantine flag after installing. The README lists macOS 15.7 as the minimum.
