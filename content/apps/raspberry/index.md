macOS 26 replaced Launchpad with the Apps view, which drops custom folders. Raspberry brings back a full-screen grid of applications that you can organise into your own groups through right-click menus, search, page through with the arrow keys and reorder with keyboard shortcuts. It indexes installed apps on first launch without relying on Spotlight and picks up new ones afterwards.

The free edition is published on GitHub releases. A paid Pro edition, whose source is also in the GPL-licensed repository, adds saved layouts and a migration path for Launchpad groups created before macOS 26. The README lists macOS 15 or later.
