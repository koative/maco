AeroSpace is a tiling window manager inspired by i3. It uses its own workspaces and a tree-based layout model to organize windows across monitors.

It runs as a macOS application but is designed around text configuration and keyboard or command-line control. The upstream guide covers setup and its differences from native Spaces.
