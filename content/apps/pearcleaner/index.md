Pearcleaner helps review installed applications, associated support files, and remnants left by previously removed software. Its file lists make it possible to inspect what will be removed before committing to a cleanup.

Use the official GitHub releases for downloads and review each deletion selection. The code is published, but the additional Commons Clause restriction means this listing is classified as source available.
