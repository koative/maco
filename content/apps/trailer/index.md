Trailer connects to GitHub or GitHub Enterprise with an API token and lists pull requests and issues from the repositories you watch, grouped into sections such as mine, participated and mentioned. Its menu item turns red for unread comments, and Notification Center alerts cover comments, merges and status updates.

Because it follows watched repositories, large organisations can produce a lot of noise until you adjust per-repository display settings. It has been maintained since 2013, and an iOS companion is published separately.
