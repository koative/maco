KeePassXC stores credentials in an encrypted local database and includes tools for organizing entries and generating passwords. Optional browser integration helps fill credentials on websites.

You choose how to back up or synchronize the database. The upstream code permits GPL version 2 or version 3; bundled components and artwork carry the additional notices in COPYING.
