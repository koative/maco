AI Dictation turns speech into text wherever you can type. On the Mac a configurable shortcut starts recording, and the transcript is inserted into the active app. Personal vocabulary, replacements, writing rules and spoken shortcuts shape the result.

Recognition can run offline or in the cloud, and an optional cleanup step may send transcripts for processing, so disable cloud features if nothing should leave the device. The README lists macOS 13 or later; Windows, iOS and Android versions also exist.
