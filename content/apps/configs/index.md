Configs collects the configuration files scattered around a home folder, such as shell profiles, Git settings and Vim configuration, and lets you edit them in a syntax-highlighted editor. Files can be grouped and given colour labels, and editing a shell profile can re-source it on save.

Every change is recorded with Git behind the scenes, so earlier versions can be compared and restored. The interface is available in English and Chinese, requires macOS 13 or later, and is distributed as a disk image on GitHub releases.
