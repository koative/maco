StockDock keeps a watchlist and portfolio in the menu bar, with live prices for anything that has a Yahoo Finance symbol: stocks, ETFs, indices, crypto and currencies. Holdings in different currencies are converted to yours, and a desktop window adds charts, news search and after-hours prices.

There is no account or API key; the app talks only to Yahoo Finance, plus a Discord or Slack webhook if you enable it, so it depends on that data feed staying available. It requires macOS 14 or later and is distributed through GitHub releases and the developer's Homebrew tap.
