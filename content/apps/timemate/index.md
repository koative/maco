TimeMate runs a Pomodoro cycle from the menu bar: focus sprints, short breaks and periodic long breaks follow one another automatically, with adjustable durations and gentle notifications at each change. An optional full-screen overlay nudges you to step away during breaks, and the Mac can be kept awake while a focus session is running.

The interface is available in English and Vietnamese. The project's website points to a free Mac App Store listing, which is the official download; the repository has no GitHub release builds. The README lists macOS 13 or later.
