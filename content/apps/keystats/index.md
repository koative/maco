KeyStats keeps a running tally of how you use your keyboard and mouse each day: key presses, left and right clicks, how far the pointer has moved and how far you have scrolled. The headline numbers sit in the menu bar, with a more detailed view a click away.

It needs Accessibility permission to observe input events. A Windows version is maintained in the same repository, and multi-device sync is optional and end-to-end encrypted according to the project. Releases are on GitHub, and the developer also maintains a Homebrew tap.
