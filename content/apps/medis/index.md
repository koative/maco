Medis provides a desktop interface for Redis databases. It helps developers browse keys and inspect values without carrying out every operation in a command-line client.

The MIT-licensed repository contains the original Electron-based Medis; its newest macOS build on GitHub Releases dates from 2016. The official site now distributes Medis 2, a separate native rewrite that is not part of this repository.
