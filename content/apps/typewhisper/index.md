TypeWhisper turns speech into text anywhere on the Mac. Transcription can run with on-device models or through cloud providers such as Groq or OpenAI, and the result can be passed through reusable AI workflows before it is inserted. History, undo for the last dictation and Finder file transcription are built in.

The code is GPL-3.0-or-later, with commercial licenses offered for uses outside GPL terms. The project's name and app icon are reserved trademarks. Stable releases and daily builds are both on GitHub, so pick a non-daily release for everyday use.
