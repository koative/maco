Notenik keeps every note in its own plain-text file, and a folder of notes forms a Collection that can live anywhere, including a synced cloud folder. Notes start with a title and a Markdown body, and each Collection can add further fields, tags and its own structure, so the same app can hold a journal, a reading list or a set of reference pages.

Notenik also covers organizing and publishing notes; the project's own documentation and website are maintained as Notenik Collections. The Mac interface code moved from the older notenik-swift repository to Notenik-25 in 2025, alongside separate MIT-licensed libraries, and the app is distributed through the Mac App Store.
