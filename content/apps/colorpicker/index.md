Colorpicker is a compact window for working with colour values. It includes a screen eyedropper, shading bars for hue and lightness, a random colour button, and Colorsbook for saving palettes, and it can be pinned above other windows.

It is an Electron app available for macOS, Windows, and Linux; GitHub releases include Apple silicon and Intel DMGs.
