Streaker shows your current and best GitHub contribution streaks and recent contribution counts in the menu bar. The icon changes depending on whether you have contributed today, and an optional notification reminds you before a streak lapses.

It is a small Electron utility; the current GitHub release offers an Apple silicon macOS build alongside Windows and Linux packages. Treat it as a motivation tool rather than a measure of productive work.
