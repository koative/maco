Peninsula turns the area around the MacBook notch into a small control surface. It can replace Command-Tab with a window switcher that supports search, show badge counts for chosen apps, hold files in a temporary tray and run countdown timers.

Parts of the code build on AltTab, NotchDrop and Doll, which the README credits. Releases are zip downloads that must be approved in Privacy & Security on first launch, and the app needs Accessibility access to list windows and read notification counts.
