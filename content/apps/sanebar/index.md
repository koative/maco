SaneBar keeps the menu bar tidy by moving items into hidden sections. Hidden apps can be reached from an icon panel or a second menu bar, with search, profiles, styling options, triggers that reveal items automatically, and an optional Touch ID lock.

Once a paid app, it was released for free under the MIT license when its developer stepped back, citing macOS 27 menu bar changes that break menu bar managers. It is now community-maintained; expect problems on macOS 27. The README lists macOS 14 or later and Apple silicon only.
