Wire is an end-to-end encrypted messenger for text chats, voice and video calls, and file sharing, used by individuals as well as teams. This repository holds the Electron-based desktop client, and the same account also works on phones and in the browser.

Wire distributes the macOS app through its download page and the Mac App Store, and installer packages appear on the project's GitHub releases. The code is GPL-3.0, but Wire Swiss GmbH reserves its name and logos, and its README sets extra conditions under Wire's terms of use for self-built clients that connect to Wire's servers.
