Quotio gathers the usage limits of AI coding services, such as Claude, OpenAI Codex, Gemini and GitHub Copilot, into one dashboard and menu bar readout, with reset times and notifications. Provider accounts are added through their supported sign-in or key methods and kept out of project files.

The app can also start and monitor a local CLIProxyAPI instance and point coding agents like Claude Code, Codex CLI, Amp and OpenCode at it, keeping their existing settings intact. A separate command-line version covers scripts and headless machines. Signed DMGs are on GitHub releases, which currently lead with 1.0 beta builds alongside earlier stable versions.
