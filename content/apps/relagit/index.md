RelaGit is a desktop client for working with Git repositories through a graphical interface instead of the terminal. Its roadmap marks submodule support and a commit graph as done, and it currently drives the Git command-line tool underneath.

The project labels itself an early beta, and its last release was in April 2026, so expect rough edges. GitHub releases include separate Apple silicon and Intel macOS builds.
