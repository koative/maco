App Downloader is a small search window over the Homebrew Cask catalogue. Type an app name and it lists matching casks with the publisher's own download address, which opens in your web browser, so you can fetch installers without using Homebrew on the command line.

It is a modest, lightly maintained tool: the last release, version 1.0.5, came out in March 2023, and the author's to-do list still mentions a settings window fix and checksum verification. Downloads come from the original vendors rather than from the app itself.
