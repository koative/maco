Buffer keeps a history of copied text and images behind a global shortcut, by default ⇧⌘V. Items can be searched, pinned, bookmarked, tagged and edited inline, several can be selected and pasted together, and text in copied images is recognised on the device so screenshots become searchable.

It is built for large clips as well, with lazy previews and disk-backed storage for multi-megabyte text, and filters out rapid duplicate copies. History stays on the Mac. Separate Apple silicon and Intel builds are published on GitHub releases.
