Poirot reads the transcripts and settings Claude Code keeps in your home folder and presents them as a browsable history: sessions grouped by project, full conversations with tool calls and thinking blocks, file diffs, and a fuzzy search across all of it. A dashboard adds token and cost breakdowns, and the menu bar can show subscription rate-limit gauges.

It also gives a view onto Claude Code's configuration, including slash commands, skills, MCP servers, hooks, plugins, plans and per-project memory, and can create and edit custom sub-agents. Downloads are DMGs on GitHub releases, with a Homebrew tap from the project. The repository was previously published as leonardocardoso/poirot.
