Markdown Preview opens `.md` files as clean, readable documents with a navigable outline of their headings, so README files and notes can be read without an editor or a browser tab. Settings cover text size, content width, alignment, line-break handling and themes, and a Quick Look extension renders Markdown when you press Space on a file in Finder.

Reading is the focus, but files can also be edited with a formatting toolbar. Signed and notarised disk images are published on GitHub and through the official Homebrew cask.
