Qingjian (青简) is a pinyin input method written in Rust. It types Chinese as you would expect, with whole-sentence input, abbreviations, typo correction, shuangpin and wubi, and adds a single translated word in English, Japanese or Spanish next to each candidate so vocabulary practice happens during ordinary typing.

Conversion, dictionary lookups and habit learning run on the device, and typing and vocabulary statistics stay local. An optional cloud suggestion feature, off by default, sends nearby text to an AI provider you configure yourself. The macOS version requires macOS 13 and is still described as a beta.
