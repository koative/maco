Padloc stores passwords, notes, one-time-password secrets and files in end-to-end encrypted vaults that sync between devices. Vaults can be shared inside an organization, with groups to manage who sees what, and the same account works in the desktop apps, the web client, mobile apps and a browser extension.

All of those clients, along with the server, live in one monorepo, so a team can run its own instance instead of the hosted padloc.app service. The macOS desktop app is distributed as Apple silicon and Intel DMGs on GitHub and through the Homebrew cask. The code is AGPL-3.0, with commercial licences offered separately by the developers.
