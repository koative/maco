AltTab provides a window switcher with thumbnails, making it easier to pick a specific window when several apps have multiple documents open. Its behavior and shortcuts are configurable.

You can tune which windows appear and how previews are arranged. macOS permissions are needed for window control and preview capture; the project explains the setup.
