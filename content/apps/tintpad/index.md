Tintpad is a keyboard launcher that drops out of the MacBook notch, or below the menu bar on other Macs. Choose a repository and press Return to open it in your existing terminal with Claude Code, Codex or another agent CLI started. It remembers frequent repositories and can create worktrees or run an agent in the background.

Clear labels show which command and permission mode will run, and modes that skip permissions are highlighted. It works locally without an account, and requires the agent CLIs to be installed separately.
