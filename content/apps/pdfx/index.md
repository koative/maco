PDFx is a small viewer for handling many PDFs together. Dropped documents, images or folders appear on one canvas, each as a horizontal strip of pages, and can be reordered or removed before exporting everything as a single file.

That file is an ordinary PDF that any reader shows page by page; PDFx also embeds a short manifest so it can split the bundle back into its original documents later. The format is documented in the repository. It is an early project, first released in 2026, with Mac builds on GitHub releases.
