Pear Desktop wraps the YouTube Music web player in a standalone desktop window and adds optional plugins on top. The bundled set covers things like synced lyrics, an equalizer, crossfade, SponsorBlock, Discord status, scrobbling, picture-in-picture and a downloader, each of which can be enabled individually.

The project was previously published as `th-ch/youtube-music` and is independent of Google. It needs a working YouTube Music account and connection to play anything. macOS builds are attached to each GitHub release, and the maintainers also provide a Homebrew tap.
