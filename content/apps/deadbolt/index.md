Deadbolt reduces file encryption to choosing a file or folder and entering a password. Encrypted files can be decrypted with Deadbolt on macOS, Windows, or Linux, which makes it useful for sending a protected document to someone on another platform.

A companion command-line tool is available for scripting. The protection depends on the strength of the password you choose.
