OmniWM combines scrolling window containers with a split-based tiling layout, selectable per workspace. It includes multi-monitor routing and optional local automation commands.

The current application targets Apple Silicon Macs on macOS 26 or later. Review its compatibility guide when choosing a window manager for an older system.
