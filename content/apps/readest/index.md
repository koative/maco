Readest is an ebook reader for people who keep a personal library of EPUB and similar files. It focuses on comfortable reading, with layout and typography controls, highlights, notes, and a library view for organising books.

The same app is available on other desktop and mobile platforms, and an optional account can keep reading progress in step between them. The macOS download is a universal DMG on GitHub releases.
