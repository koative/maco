Kaku is a macOS terminal built on WezTerm that tries to be comfortable without a configuration session first. It arrives with JetBrains Mono, automatic light and dark themes, copy-on-select, familiar Mac shortcuts, tabs and split panes that are restored when you reopen it, and a right-click menu for common actions.

An optional assistant can suggest commands or chat alongside your coding tools, and the full WezTerm Lua configuration is still available. Disk images are on GitHub releases and the app is in the official `kaku` Homebrew cask.
