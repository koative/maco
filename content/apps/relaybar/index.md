RelayBar keeps SSH tunnels as named profiles in the menu bar, so local, remote and dynamic forwards can be started and stopped without retyping commands. Existing forwarding commands can be imported, and the app runs macOS's own ssh client with the user's normal config and known hosts.

Newer versions add a Remote Files workspace for browsing, previewing and uploading files on a host over sftp. Releases ship as a zipped app on GitHub and through the developer's Homebrew tap.
