DynamicNotch borrows the iPhone's Dynamic Island idea for the Mac: the black area around the camera notch expands into small live panels for the current track, download progress, AirDrop transfers, timers and screen recording, and briefly shows status changes such as charging, Bluetooth connections, Wi-Fi or VPN. Swipes and drags dismiss or restore these panels, and on Macs or external displays without a notch it draws a floating capsule instead.

Notch size, outline, background and animation style are adjustable, and individual features ask for Accessibility, Bluetooth or Screen Recording access only when they need it. The README lists macOS 14.6 or later; builds are published on the project's GitHub releases page.
