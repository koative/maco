Voxt is a dictation tool that shows a live transcript while you speak and inserts the result where you are typing. Beyond plain transcription, it can translate what you said, translate selected text with a shortcut, or treat your speech as a prompt and insert the generated text instead. Note Mode and Meeting Mode handle longer recordings.

The app started in the hehehai/voxt repository, which is now archived; development continues in the Voxt folder of the SGLang-Omni repository under the same Apache 2.0 license. Builds are still published on the original repository's releases page, the official website and the author's Homebrew tap.
