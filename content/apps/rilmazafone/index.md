Rilmazafone lets Mac developers lay out a DMG window as it will appear in Finder, with the app icon, extra files, the Applications shortcut and a composed background. Layouts are saved as reusable templates.

The GitHub edition adds a release pipeline that archives, signs, notarizes, packages and verifies an app, publishes a GitHub release and updates a Homebrew cask, with matching command-line tools. A Mac App Store edition contains only the designer. The project lists macOS 26 or later, with Xcode for the release pipeline.
