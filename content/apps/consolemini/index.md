ConsoleMini is a big-screen game library meant for a Mac connected to a TV. It lists games by system and hands them to installed emulators such as DuckStation, PCSX2, PPSSPP or RetroArch, so the whole session can be driven from a game controller.

It does not include emulators, BIOS files or games; those are installed separately. The Electron app is early, at version 0.1, with Apple silicon and Intel disk images on GitHub releases.
