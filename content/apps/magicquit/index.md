MagicQuit closes apps automatically in two optional ways: after they have sat unused for a configurable time, or as soon as their last window is closed. Both work from an exclusion list, and media players are excluded from window-close quitting by default.

Apps are quit normally, as with Command-Q, so unsaved documents still prompt. The window-close feature needs Accessibility permission. The README lists macOS 14 or later and mentions MIT, but the repository's LICENSE file contains GPLv3, which this listing follows.
