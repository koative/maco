Fluor remembers whether each app should get the Mac's brightness and media keys or plain function keys, and flips the keyboard's mode as you switch apps. Its menu bar icon shows the current mode, a rules editor lists every per-app setting, and a running-apps panel covers programs, such as some games, that are hard to pick from a file dialog.

The latest release is 2.5.1 from July 2022, and the project's former website no longer resolves. It remains available from GitHub releases and as a Homebrew cask.
