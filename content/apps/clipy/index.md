Clipy stores clipboard history and provides a separate menu for saved snippets. It gives repeated text a convenient place to live instead of requiring you to find and copy the original each time.

The main menu, history, snippets, and settings have configurable shortcuts. Its upstream documentation explains Accessibility permissions and data handling.
