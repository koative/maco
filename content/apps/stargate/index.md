Stargate combines a pattern-based DAW with its own suite of instrument and effect plugins, a basic wave editor and a routing matrix that makes sidechaining straightforward. It aims to cover a full music production workflow, with a particular eye on electronic music.

Releases include separate macOS disk images for Intel and Apple silicon. The latest release dates from January 2024 and source activity has been sparse since, so treat it as lightly maintained.
