Chops finds the skill and agent definition files that coding assistants keep in scattered dot-folders and shows them in one library. It covers Claude Code, Cursor, Codex, Windsurf, Amp, Copilot and Aider, watches the folders for changes, and offers full-text search, collections that do not touch the underlying files, and a built-in editor that understands frontmatter.

New skills and agents can be created with the right boilerplate for each tool, browsed from remote servers, or installed from the skills.sh registry. It requires macOS 15 or later and ships as a DMG from GitHub releases.
