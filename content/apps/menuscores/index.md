MenuScores lists current games from a menu bar icon and lets you pin one to the menu bar or the notch so the score stays visible while you work. Favourite teams can be pinned automatically once their games go live, and optional notifications mark the start and end of a pinned game. The project covers more than 60 leagues across 13 sports.

Releases are distributed as an unsigned DMG, so macOS asks for a manual approval in Privacy & Security on first launch; the README also documents the author's Homebrew tap. It requires macOS 13 or later.
