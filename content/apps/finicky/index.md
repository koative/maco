Finicky acts as a default link handler and chooses which browser should open each URL. Rules can separate work and personal sites or rewrite a link before sending it onward.

Configuration uses JavaScript or TypeScript. The upstream examples are a useful starting point for matching domains, browser profiles, and other conditions.
