massCode began as a snippet manager and now covers more of a developer’s notebook: organised code snippets with syntax highlighting, Markdown notes, an HTTP request client, calculations, and assorted conversion tools.

Data is stored locally on your Mac. GitHub releases include Apple silicon and Intel builds alongside Windows and Linux packages.
