Easydict is a lookup and translation panel that appears when you select text, type a query or capture part of the screen for OCR. It can query several services at once and compare their results, from Apple Dictionary and Apple Translate to web translators and AI models, including local ones through Ollama.

Some services need their own API keys or accounts, and the project documents the access requirements for each. Releases are distributed on GitHub and through Homebrew.
