ExifCleaner removes EXIF and other metadata from supported image, media and PDF files that you drop onto its window, including whole folders. Options can preserve orientation or timestamps, save cleaned copies instead of overwriting, and remove macOS extended attributes; an expandable view compares metadata before and after.

It uses ExifTool for processing and works offline without automatic updates. Check the supported formats list before relying on it for anything sensitive.
