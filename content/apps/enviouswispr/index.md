EnviousWispr records while you hold or toggle a shortcut, stops when you finish speaking, transcribes locally and pastes the result into the app you were using. Parakeet covers European languages with the lowest latency, while Whisper handles a much wider set of languages with automatic detection; no account is needed and transcription works offline.

An optional polish step can tidy grammar and punctuation using on-device models, Apple Intelligence, Ollama, or cloud services with your own API key. The app code is GPLv3, but the project's own EG-1 polish model is not open source and downloads separately under its own terms. The project targets Apple silicon Macs and publishes DMGs on GitHub.
