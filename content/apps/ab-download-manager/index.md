AB Download Manager takes over file downloads from the browser and keeps them in a dedicated window, where they can be paused, resumed, grouped into queues and started on a schedule. Companion browser extensions, published in a separate repository, hand links to the app.

It is released for macOS, Windows, Linux and Android. The project warns that copies offered in app stores it does not list are not official; macOS disk images are on its GitHub releases.
