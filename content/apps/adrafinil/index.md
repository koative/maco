Adrafinil listens to hooks from coding agents such as Claude Code, Codex, Cursor and Gemini CLI and holds off sleep, even with the lid closed, while any of them is mid-task. When the last session finishes, normal sleep resumes; a thermal cutout and cleanup of abandoned sessions limit unattended runs.

The current release needs macOS 26.4 or later and administrator approval for a privileged helper; the README links a community backport for macOS 15. It is also available as a Homebrew cask.
