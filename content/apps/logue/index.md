Logue combines a block-based document editor with nested spaces, typed properties, relations between pages, wiki-style links with backlinks and saved, filtered views, in a shape that will feel familiar to Notion or Obsidian users. It also records meetings, transcribes and separates speakers, drafts minutes and turns commitments into tasks inside the same workspace.

The project says its transcription, summarisation and agent run on the Mac through MLX on Apple Silicon, with network use limited to model downloads, update checks and features you opt into. Documents can be stored encrypted or kept as plain Markdown files in a folder of your choice. It is a young project: version 1.0 arrived in mid-2026.
