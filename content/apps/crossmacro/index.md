CrossMacro captures a sequence of clicks, pointer movement and keystrokes and plays it back on demand, so repetitive form filling or routine desktop chores can be done once and replayed. Saved macros can be edited visually, bound to shortcuts, run on a schedule, or started when a matching window gains focus, and a text-expansion feature turns short abbreviations into longer text.

The same app runs on Linux, Windows and macOS. The project publishes separate Apple silicon and Intel DMGs for macOS 14 or later; they are unsigned, so the macOS setup guide walks through Gatekeeper and the Accessibility and Input Monitoring permissions needed before recording.
