CC Switch is a desktop manager for the configuration files behind AI coding tools such as Claude Code, Codex, and Gemini CLI. Instead of editing JSON, TOML, or environment files by hand, you save provider presets and switch the endpoint, key, and model in one step.

It also keeps MCP servers, skills, and prompts in one place across the supported tools. The upstream README carries sponsor promotions for third-party API resellers; using those services is unrelated to the app itself.
