Penc activates a window-control mode by double-pressing and holding Command. Drag, pinch, or swipe with the trackpad to position the current window, then release the key to finish.

It requires Accessibility permission and the trackpad pinch gesture to be enabled for resizing. The project provides a downloadable macOS disk image.
