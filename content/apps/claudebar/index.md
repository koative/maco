ClaudeBar shows how much of each AI coding plan is left from the menu bar. Despite the name it covers about twenty providers, including Claude, Codex, Gemini, Copilot, Cursor, Kimi and OpenRouter, each switched on separately and showing its own session, weekly, monthly or credit limits.

Countdowns show when each window resets, and a notification arrives before a quota runs out. Signed and notarized builds for macOS 15 or later are on GitHub releases and in Homebrew.
