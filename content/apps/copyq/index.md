CopyQ keeps a clipboard history and lets you organise saved items into tabs, add notes and tags, edit entries in place and paste them back with global shortcuts. Beyond plain text it stores HTML, images and custom formats.

Its strength is automation: custom commands, a command-line interface and a scripting API can transform or route clipboard content. That depth comes with a busier, cross-platform Qt interface than single-purpose Mac clipboard tools. Exclude password managers and other sensitive apps before keeping a long history.
