Shotnix combines a screenshot tool and a screen recorder. Captures can cover an area, a window, whole displays or a scrolling page, then be annotated with arrows, text, numbered steps, highlights and blur, pinned on screen, or kept in a history; text recognition copies text out of any image.

Recordings open in a built-in editor that adds zooms on clicks, a smoothed cursor and captions generated on the Mac. The project requires macOS 13 or later and still tags its frequent GitHub releases as beta.
