Cerebro opens a search bar from a global shortcut and returns apps, files with previews, web searches, calculator results and unit conversions. Additional sources can be installed as plugins from within the launcher.

It is an Electron app with configuration in a JSON file and light and dark themes. The repository still receives changes, but the latest packaged release at review time was 0.11.0 from February 2023.
