Textual is an IRC client that supports IRCv3, SASL, client certificates and bouncers such as ZNC. Chat styles are written in HTML, CSS and JavaScript, and it can be extended with plugins and scripts.

The source is BSD-licensed, with portions inherited from LimeChat under a two-clause BSD license. Official builds are sold after a 30-day trial. The project changed maintainers in 2026: the current release's source lives on the `v7` branch while `main` is being reworked for Textual 8.
