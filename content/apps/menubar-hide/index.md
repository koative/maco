MenubarHide tidies a crowded menu bar. Icons you drag to the left of its separator are tucked away and brought back with a click or a keyboard shortcut. On a notched MacBook it can instead show the hidden icons in a floating panel beneath the menu bar, so they stay reachable even when there is no room beside the notch.

It can also tighten the spacing between status items and remember an icon layout so apps that launch late return to their places. The project documents that macOS 27 changed the menu bar: hiding still works there through the system overflow menu, but the panel and layout features are limited to macOS 26 and earlier. Signed builds are on GitHub releases.
