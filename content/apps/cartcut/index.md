CartCut is a desktop video editor that uses layers rather than tracks, making it easier to stack effects on individual assets. It covers cutting, keyframed position, scale, opacity and rotation, text, chroma key, transitions, audio mixing and FFmpeg-based rendering, plus Whisper-powered automatic captions.

It can expose its live timeline over MCP so coding agents and other MCP clients can perform edits on request. The repository was previously named nugget-app; macOS builds for Apple silicon and Intel are on GitHub releases.
