Acid Cam is an experimental video art tool. A session starts from a webcam or a video file, and the image passes through one or more filters chosen from a very large catalogue, which can be stacked, faded between and tuned with colour sliders while the video plays. The result can be recorded to a file or passed to other software through Syphon.

It is a long-running personal project that began in 2011. Output is written at very high bitrates, and the more elaborate filters need plenty of memory. The latest macOS build is 2.84.0 from February 2023, published on GitHub releases for macOS 10.13 or later.
