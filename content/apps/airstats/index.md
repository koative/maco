AirStats shows system readings in the menu bar, in a drop-down panel with more detail, and in a desktop widget. It covers processor and memory load, GPU, network and disk activity, battery state, temperatures and top processes.

Keeping its own resource use small is the main design goal, and it runs without a Dock icon. The project states that it requires macOS 14 or later on Apple silicon. Updates are checked through Sparkle, which can be switched off.
