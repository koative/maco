Apple Notes has no way to export a whole library, so this app reads the Notes database directly and writes every note out while keeping the folder structure. Output formats include HTML, PDF, Markdown, LaTeX, DOCX, ODT, EPUB and Evernote's ENEX, and an export can be delivered as a folder tree, a ZIP or TAR archive, or one combined file.

Recent versions also offer incremental sync runs, a command-line tool, Shortcuts actions and an MCP server for AI assistants. The app needs Full Disk Access to read the Notes data, requires macOS 11 or later, and is published as a zip on GitHub.
