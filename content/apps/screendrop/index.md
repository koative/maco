Screendrop is a menu bar capture tool that grabs a display, window or region as an image or recording, then keeps the result in a floating preview stack for copying, annotating, pinning or saving. The editor adds redaction, backgrounds and cropping for screenshots, and zooms, cursor effects, captions and transcript-based cutting for recordings; text can also be lifted from the screen with on-device OCR.

For sharing in the style of hosted video-message services, recordings can be uploaded to the user's own Cloudflare account rather than a third-party server. The project warns that it is under active development with occasional breaking changes, and it requires macOS 26.4 or newer. Disk images are on GitHub releases, and the author also maintains a Homebrew tap.
