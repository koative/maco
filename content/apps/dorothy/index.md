Dorothy is an Electron app that runs command-line coding agents such as Claude Code, Codex and Gemini CLI side by side, each in its own terminal session tied to a project. A coordinating agent can hand out work to the others, and tasks can be organised on a Kanban board, triggered by GitHub events or run on a schedule.

It also tracks usage, manages agent skills and MCP servers, and can be steered remotely through Telegram or Slack. The agents themselves must be installed separately, and some modes let them run without asking for permission, so configure it carefully. The current GitHub releases ship arm64 DMG and ZIP builds.
