TomatoBar provides a small Pomodoro-style timer with adjustable work and rest periods. Notifications, optional sounds, and a global shortcut help you manage the timer without a large window.

Its event log and URL controls can connect the timer to a broader workflow. The upstream repository provides macOS releases and describes those integrations.
