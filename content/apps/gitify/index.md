Gitify sits in the menu bar and shows your Git notifications without keeping a browser tab open. Besides GitHub and GitHub Enterprise it can connect to GitLab, Bitbucket Cloud, Gitea, Forgejo, and Codeberg accounts, and it lets you mark items read or done, unsubscribe, and jump straight to the issue or pull request.

Filters, themes, and other settings control what appears and how it looks. The app also runs on Windows and Linux; Mac users can download a universal build from the website or GitHub Releases, or install the `gitify` Homebrew cask.
