Nimble Commander puts two file panels side by side in the manner of the classic file managers of the 1980s and 1990s, with most work done from the keyboard: moving through folders, copying and moving between panes, and acting on selections without reaching for the mouse. It aims to pair that workflow with the look and feel of a modern Mac app.

The source is published under GPLv3. Current builds are available from the project website, GitHub releases and Homebrew, with a user guide and changelog kept in the repository; earlier releases are archived in a separate repository.
