Cate opens a project folder as a zoomable canvas where editor, terminal, and browser panels can be placed side by side. It is designed around running several agent CLIs such as Claude Code or Codex at once, showing which terminals are busy, finished, or waiting for input and notifying you when one needs attention.

This is a young project with frequent releases. GitHub releases include Apple silicon and Intel builds for macOS, plus Windows and Linux packages.
