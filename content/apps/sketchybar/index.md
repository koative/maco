SketchyBar draws a custom bar that can sit over or replace the macOS menu bar. Every item, label, graph, popup and animation is created and changed at runtime through commands, and an event system lets scripts react to things like space changes, media playback or system state.

There is no settings window: configuration lives in a shell script and plugin scripts, and installation goes through the project's Homebrew tap as described in the setup guide. It suits people who are comfortable building their own desktop setup from scripts.
