Notes is a cross-platform note-taking app built with C++ and Qt. Notes are written in Markdown and organised with nested folders and tags; a feed view shows several notes in sequence, and Markdown task lists can be displayed as a Kanban board. Light, dark and sepia themes are included.

Editing inside the Kanban view is part of an optional paid Pro license. The most recent tagged release on GitHub, 2.3.1, dates from October 2024 and includes macOS disk images.
