Downright treats Markdown files as regular Mac documents. There is no library or vault to set up: open a file wherever it lives, read it as formatted text with tables, math, diagrams and footnotes, or switch to the source view to edit it, with the original text left untouched on disk.

It also adds Quick Look previews and Finder thumbnails for Markdown, exports to HTML and PDF, and keeps local snapshots of earlier versions. It works offline without an account and requires macOS 14 or later. Signed builds are published on the project website and GitHub releases.
