espanso watches for keywords as you type and replaces them with longer text: canned replies, code snippets, emoji, dates, or the output of shell commands and scripts. Matches are defined in configuration files, can be app-specific, and can open small forms for filling in values.

A search bar helps find matches, and a package manager installs shared collections from the espanso hub. It runs on macOS, Windows and Linux and keeps processing local.
