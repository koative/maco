Seashore is a raster image editor built around layers, aimed at simple everyday image work rather than professional retouching. It began as Mark Pazolli's SourceForge project, and this repository is the version Robert Engels has modernised and publishes for free on the Mac App Store.

Its author has since shifted active development to Seahorse, a separate paid app, but says Seashore stays free on the App Store and will be kept running on newer macOS versions with critical fixes. The last tagged source release on GitHub is 3.36 from 2024; the App Store build was updated in 2026.
