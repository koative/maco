Point Localization Editor at a project folder and it gathers the Localizable.strings files for each language into one table, keyed by string identifier. Gaps show up as empty cells, and edits are written straight back to the matching strings file.

The last release, 2.9.2, came out in December 2023. Builds are signed only with a development certificate, so the first launch needs the Open command from the Finder context menu.
