WhatsYourSign adds a Finder menu action for viewing cryptographic signing information. It makes it easier to inspect an application or executable without assembling terminal commands.

A valid signature identifies signing information; it does not by itself establish that software is trustworthy. The upstream product page explains the fields shown.
