Edmund edits Markdown files directly in place with an inline live preview, similar to Typora or Obsidian, without requiring a vault or library folder. Math and Obsidian-style syntax are opt-in, and it is offline by default with options to block external links and sanitise HTML.

The project is in beta. Builds are not signed with an Apple Developer certificate, so macOS may refuse the first launch until you clear the quarantine flag as the README explains.
