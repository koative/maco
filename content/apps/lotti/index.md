Lotti is a personal record of your work and life: tasks, projects, journal entries, voice notes, screenshots, photos and tracked time all live in one local database. Devices you pair sync with each other through an end-to-end encrypted Matrix room, so the relay only ever sees ciphertext. AI agents can read what you have recorded and suggest task updates or summaries, but changes only land once you approve them.

The project has been in development since 2016 and is built with Flutter for macOS, Windows, Linux, iOS and Android. Signed and notarized macOS DMGs are attached to its GitHub releases; most builds are marked as pre-releases, so pick the latest stable one if you prefer.
