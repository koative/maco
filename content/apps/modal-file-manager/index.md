Modal File Manager navigates and manages files through modes and hotkeys in the spirit of Vim, with customisable key bindings, themes and extensions. It is built with Svelte and Wails, and its configuration can be extended with scripts.

The author warns that file operations can permanently delete data, and drag and drop to other apps is limited. The latest macOS build is a universal zip on GitHub releases.
