Notational Velocity is built around a single field at the top of the window. Typing there filters every note whose title or body contains your words, pressing Return creates a note with that title, and the body underneath is edited directly, with changes written to disk continuously instead of through a Save command. Almost everything is reachable from the keyboard, and the app inspired later forks such as nvALT.

The previous tagged release dates from 2011, but the original author resumed work in 2026: versions 2.5.1 and 2.5.2 were published on GitHub in October 2026 with fixes for macOS 26, and current builds declare macOS 11.5 as the minimum. The project is GPL-3.0; downloads are the zip files attached to its GitHub releases.
