Pock replaces the Touch Bar's default controls with a row of widgets. The main one mirrors the Dock, complete with notification badges, so apps can be switched without the on-screen Dock taking up space; others show what is playing with gesture-based media controls, keep an Escape key handy, display the time, Wi-Fi and battery status, and adjust brightness and volume. Widgets are configured from a menu bar item.

It only does anything on MacBook Pro models that have a Touch Bar. The latest build, 0.9.0, dates from September 2021 and is offered from pock.app and the Homebrew cask; it is marked as a pre-release on GitHub, and the repository has seen little activity since 2022. The README notes that it sends anonymous diagnostics events.
