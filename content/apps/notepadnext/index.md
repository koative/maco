Notepad Next brings the Notepad++ way of working to platforms the original never supported, including the Mac. It is built on the Scintilla editing component that Notepad++ also uses, aiming to give long-time Notepad++ users a familiar editor outside Windows.

The project is candid that it is still a work in progress: the author describes it as stable and usable, but warns that some features are incomplete and that it should not be trusted with critically important work. macOS disk images are published on the GitHub releases page alongside Windows and Linux builds.
