Keyty draws an overlay of the keys you press and the clicks you make, so viewers of a screen recording or live demo can follow along. Overlay style, size, position, history and filters for modifier, special and media keys are adjustable, and optional pointer rings, icons and click ripples highlight the mouse.

Downloads are published on GitHub releases and through Homebrew. As with any keystroke visualizer, it needs macOS permission to receive input events and will display whatever you type while it is active, including passwords.
