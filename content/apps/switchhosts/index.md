SwitchHosts keeps several named hosts configurations, including local, remote and grouped entries, and writes the selected combination to the system hosts file. It adds syntax highlighting, find and replace, scheduled refresh of remote lists, and a trash for removed entries.

It is a cross-platform Tauri app with macOS builds on GitHub releases. Applying changes to the system hosts file may prompt for administrator approval.
