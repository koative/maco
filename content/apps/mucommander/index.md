muCommander is an orthodox, two-panel file manager in the Norton Commander tradition: browse two locations side by side and copy, move or compare files with the keyboard. It can also browse inside archives and connect to network locations.

The app is written in Java and runs on several operating systems; macOS disk images are published for Apple silicon and Intel on GitHub releases. Expect a cross-platform interface rather than a Finder-like one.
