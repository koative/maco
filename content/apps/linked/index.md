Linked gives each day its own page for thoughts, to-dos and notes, with keyboard shortcuts for moving between days and a search across all entries. Text styles, lists, to-dos and code blocks are supported, in light or dark mode.

Entries are saved as files in your Documents folder rather than a hosted service. The latest release, 1.5.2, dates from June 2023, and planned features such as sync have not shipped.
