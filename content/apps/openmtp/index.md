macOS has no built-in way to browse an Android phone's storage over USB, and OpenMTP fills that gap. It shows the Mac and the device side by side, so files and folders can be copied in either direction by drag and drop, with a choice between internal memory and an SD card and keyboard shortcuts for navigation.

Separate Apple silicon and Intel downloads are published on GitHub and the project website, and a Homebrew cask is available.
