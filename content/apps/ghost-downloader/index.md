Ghost Downloader collects many download types in one queue: HTTP files fetched in parallel chunks, magnet links and torrents, FTP, HLS and DASH streams, and video pages from sites such as YouTube and Bilibili with a choice of quality. A companion browser extension lists the media found on a page and hands it to the app, and feature packs extend it further.

GitHub releases include macOS disk images for Apple silicon and Intel next to Windows, Linux and Android packages; the project lists macOS 13 as the minimum.
