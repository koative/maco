Grayscale Mode puts the system grayscale display filter one click or shortcut away, and can switch it off automatically for apps where color matters. Some people use it to make the screen less engaging and cut distraction.

The last release, 2.1.0, is from April 2020 and the project has been quiet since, so check that it works on your macOS version. The code is MIT licensed, but the README explicitly excludes images and other assets from that license.
