JSON Model Generator, built as the JsonToModel app, takes a JSON sample and writes matching model classes. Templates are included for Swift Codable, ObjectMapper and Gloss, Java and Kotlin with GSON, Dart for Flutter, C# with Newtonsoft and Python dataclasses, and you can write your own templates.

The last release, version 1.5, was published in December 2021, and the project states a requirement of macOS 10.13 or later; newer macOS versions are not explicitly confirmed.
