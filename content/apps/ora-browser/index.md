Ora is a web browser built on Apple's WebKit engine with a SwiftUI and AppKit interface. It includes content blocking and privacy protections, customisable search engines, URL suggestions and a quick launcher.

The project states that Ora is still in active development and not yet ready for daily use, so expect rough edges. It requires macOS 15 or later, and disk images are published on GitHub releases.
