LaunchNext recreates the full-screen Launchpad grid that macOS Tahoe removed, with paged app icons, folders and fuzzy search, plus hot corners, trackpad gestures and a command-line interface. It builds on the earlier LaunchNow project and keeps its GPLv3 license.

It includes its own updater and can also be installed from the developer's Homebrew tap. Check the README for current signing status if macOS blocks the first launch.
