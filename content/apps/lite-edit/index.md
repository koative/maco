LiteEdit opens a folder with a file tree, tabs, line numbers and syntax highlighting, and remembers the session so the same files return on the next launch. Quick open and multi-cursor renaming cover the most common jobs of a secondary editor.

It is intended to sit beside a full IDE for reading code and small changes, and leaves out extensions, language servers, a terminal and Git tools on purpose. The project lists macOS 13 or later.
