Application Menu adds a menu bar item that lists your installed applications, so you can launch one without opening Launchpad, Spotlight or the Applications folder.

It is deliberately small. The README lists support from macOS Ventura through Tahoe; install it from the DMG on the releases page or the project's Homebrew tap.
