MenuMeters makes system activity visible through compact menu bar meters. It continues the original MenuMeters project with changes for later versions of macOS.

The maintainer recommends newer alternatives such as Stats for sufficiently recent Macs. This entry retains the downloadable classic utility for users who prefer its presentation.
