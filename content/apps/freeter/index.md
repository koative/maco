Freeter groups the material for a piece of work into projects and workflows built from widgets such as web pages, notes, to-do lists, file shortcuts and commands. Switching workflows swaps the whole set at once, which helps when moving between clients or recurring tasks.

A global shortcut and a menu bar icon bring it forward. The official downloads offer separate Apple silicon and Intel builds; current releases are labelled beta.
