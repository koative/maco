Warp is a terminal built around blocks: each command and its output form a unit you can select, copy, share or search, and input is edited like text in an editor rather than a single shell line. On top of that it adds a file tree, diff views and a panel for running Warp's own agent or third-party command-line agents side by side.

The client moved to an open-source repository in April 2026; its UI framework crates are MIT and the rest is AGPL-3.0. Signing in is optional, but hosted features such as Warp's AI models and Drive sync run on the company's servers. Install the signed build from warp.dev or the official Homebrew cask; self-compiled copies run as a separate `warp-oss` app without auto-updates.
