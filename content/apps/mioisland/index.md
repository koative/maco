MioIsland uses the notch area as a live panel for Claude Code and similar terminal agents: it shows session status, lists running sessions, lets you allow or deny permission requests in place, and jumps back to the right window in terminals and editors such as iTerm2, Ghostty, Terminal, Warp, Kitty, WezTerm, VS Code, Cursor and Zed. Small pixel-art buddies and 8-bit sounds give it a playful tone, and a companion iPhone app can mirror session state.

It began as a fork of Claude Island and was previously published as CodeIsland. The project lists macOS 15 or later, ships builds through GitHub releases, and documents itself mostly in Chinese. Its noncommercial license means this listing is classified as source available.
