HTTP Toolkit sits between a client and the network so you can watch HTTP and HTTPS requests as they happen, examine headers and bodies, pause traffic at breakpoints to edit it, or send requests of your own. It can target browsers, terminal sessions, backend processes, Docker containers and Android or iOS apps. Automated rewrite rules and some other features belong to a paid Pro tier.

This repository packages the open-source UI and server into a desktop app for macOS, Windows and Linux; the Mac builds are on GitHub releases and in Homebrew. The source is AGPL-3.0, and the project also offers its official binaries under CC BY-ND 4.0 for users who prefer not to rely on the AGPL.
