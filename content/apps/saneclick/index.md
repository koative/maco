SaneClick adds a library of Finder context-menu actions for converting and resizing images, handling PDFs, copying paths, hashing files and similar chores, shown only for matching file types. Power users can add their own Bash, AppleScript or Automator actions.

The source is published under PolyForm Shield 1.0.0, so this entry is classified as source available. The official download is a paid app with a free trial and requires macOS 14 on Apple silicon.
