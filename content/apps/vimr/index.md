VimR wraps Neovim in a Mac window and adds conveniences that terminal Vim lacks: a simple file browser, an Xcode-style quick-open finder, tabs, a flexible workspace layout, and live Markdown and HTML previews. Trackpad zooming and optional font ligatures round out the interface.

Your existing Neovim knowledge carries over, so it suits people who want modal editing with some GUI comfort. Signed builds are published on the GitHub releases page; the README lists macOS 13 or later.
