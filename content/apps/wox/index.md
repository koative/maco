Wox opens a single search box from a hotkey to launch apps, find files and run actions without reaching for the mouse. Plugins written in Node.js, Python or plain scripts, along with themes, can be installed from its online store.

It runs on macOS, Windows and Linux. Builds are published on GitHub releases, and a Homebrew cask is available.
