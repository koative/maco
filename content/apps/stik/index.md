Stik is built for quick capture. A global shortcut opens a post-it over whatever you are doing; when you close it, the note is saved as plain Markdown in a folder on your Mac. There is no account or sync setup.

Beyond capture it offers folders, search, pinned desktop notes, a Markdown editor with wiki links and task lists, on-device voice transcription, and optional per-note encryption. The README lists macOS 14 or later and asks for Accessibility permission for its shortcuts.
