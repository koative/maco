HotkeyClash inspects application menus, macOS shortcuts, and supported configuration files to identify overlapping key combinations. It distinguishes definite global conflicts from combinations that may only overlap in certain contexts.

Use its report to find the relevant app or setting when a shortcut behaves unexpectedly. Accessibility access is needed to inspect running applications' menus.
