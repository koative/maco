Boop is a plain text window with a command palette. Paste something in, choose a script, and the text is converted in place: format JSON, decode Base64, URL-encode, change case, count characters and much more. New scripts are small JavaScript files you can write yourself.

The last release, 1.4.0, dates from 2021, so expect no new features. It is available free from GitHub releases and the Mac App Store.
