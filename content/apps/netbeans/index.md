Apache NetBeans is a full IDE with project management, editors, debugging and build tool integration, best known for Java development. It is maintained as an Apache Software Foundation project with regular numbered releases.

The ASF publishes a platform-independent binary archive that runs on a supported JDK. The official download page also links macOS installers that bundle a JDK; these are built by NetBeans committers as a convenience and are not ASF releases themselves.
