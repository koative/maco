OpenBitFun is an agent workspace built around a Rust agent runtime. After connecting a model you open a workspace and choose how much structure a task gets, from quick back-and-forth collaboration to multi-step plans where work is split across several agents. Agents can be customised with their own roles, tools, MCP connections, Skills and hooks.

Tasks can be followed and steered from a phone or browser while they keep running on the original machine, and remote workspaces work over SSH. The app can also generate small Mini Apps for recurring jobs. The core code is MIT-licensed; desktop builds for macOS, Windows and Linux are on GitHub releases and the official download page.
