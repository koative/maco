Atomic Chat is a desktop chat client for running open-weight language models on your own machine. It downloads and manages models and switches between local inference engines, so conversations with a local model never leave the computer. While a model is loaded, the app also serves an OpenAI-compatible API on localhost, so editors, command-line agents and other clients can use the same local model.

The project credits Menlo Research in its license notice and is distributed under Apache 2.0. GitHub releases include a universal macOS build alongside Windows and Linux packages; mobile versions are listed separately.
