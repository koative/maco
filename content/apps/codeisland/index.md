CodeIsland expands from the notch into a status panel for every running coding agent session, showing what each one is doing, its latest reply and its progress. When an agent needs permission or asks a question, you can respond from the panel instead of hunting for the terminal it lives in.

It installs hooks for a long list of command-line and editor-based agents, including Claude Code, Codex, Cursor and Gemini CLI, and keeps its data on the Mac. The project lists macOS 14 or later; downloads are a DMG on GitHub releases or the developer's own Homebrew tap.
