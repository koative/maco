FlyEnv installs and runs the pieces of a local development environment directly on the Mac, without containers: language runtimes such as PHP, Node.js and Python, databases like MySQL and PostgreSQL, web servers including Nginx and Caddy, plus caches, queues, search engines and object storage. Versions can be pinned per project, and local sites get custom domains with certificates.

It is aimed at the same job as MAMP or Laravel Herd, across more languages, and also manages AI coding CLIs and a built-in MCP server. Core use needs no licence; some premium tools have evaluation limits that a one-time paid licence removes. Builds are offered for Apple silicon and Intel Macs, Windows and Linux.
