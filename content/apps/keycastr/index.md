KeyCastr shows an on-screen representation of keyboard input so viewers can follow a demonstration. Choose between command keys, modified keys, or broader key display, with optional mouse-click visualization.

It requires macOS input-monitoring permission. Position the overlay where it supports the presentation and review the display mode before sharing your screen.
