Trace sits in the background until its global hotkey opens a search field for apps, then layers extra tools on the same window: window snapping to halves and thirds, one-key quick links to files, folders and sites, a calculator, an emoji picker and a glance at calendar events.

Push-to-talk dictation is optional and, according to the project, transcribes on the Mac with Apple's Speech framework. Settings can be backed up to a self-hosted sync server. The README lists macOS 26 as the minimum; builds come from GitHub releases or the developer's Homebrew tap.
