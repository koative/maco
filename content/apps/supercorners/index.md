SuperCorners extends the idea of macOS hot corners. Each screen corner, plus additional zones at the middle of each edge, can launch an app, open a file, folder or website, run a Shortcut or AppleScript, send a keyboard shortcut or execute a system command when the pointer reaches it.

Actions can be grouped into sets that change with the frontmost app, and activation sensitivity, delay and visual feedback are adjustable. The project lists macOS 13 or later as a requirement and distributes a disk image through its GitHub releases, with a Homebrew cask in the developer's own tap as an alternative.
