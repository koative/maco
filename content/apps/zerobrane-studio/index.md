ZeroBrane Studio is a compact IDE for Lua with syntax highlighting, code completion, a static analyser, live coding and a debugger that can attach to local or remote programs. It supports Lua 5.1 to 5.4 and LuaJIT, and has debugging guides for engines and frameworks such as LÖVE, Gideros, Corona, Cocos2d-x and OpenResty.

The latest version is 2.01 from September 2023, which fixed launching on macOS Sonoma; the official site offers it as a macOS disk image alongside Windows and Linux builds. Its own sources are MIT-licensed, while bundled components such as wxLua, Lua and Scintilla keep the licenses listed in the same file.
