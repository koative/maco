electerm gathers local terminals and remote connections in one tabbed window. Saved bookmarks cover SSH with a side-by-side SFTP file browser, as well as FTP, Telnet, serial ports, and remote desktop protocols such as RDP and VNC.

It is an Electron app with themes, quick commands, and optional settings sync. GitHub releases provide separate macOS builds for Apple silicon and Intel, plus an extra Intel build labelled for macOS 10.
