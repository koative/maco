qView is an image viewer built around minimalism: it opens a picture in a plain window and keeps the interface out of the way, leaving the image as the focus.

It is a Qt application that also runs on Windows and Linux. Version 7.1 ships a standard and a legacy macOS DMG on the releases page, with nightly builds offered separately.
