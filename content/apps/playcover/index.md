PlayCover wraps decrypted iOS app packages so they run on Apple silicon Macs as if on an iPad, then lets you map touch controls to keys, mouse movement and game controllers. It is mostly used for mobile games that lack an official Mac version or proper keyboard support.

You must supply the app packages yourself, and the project notes that not every app is supported and some may have bugs. It does not run on Intel Macs. The latest stable release at review time was 3.1.0, with a 4.0 prerelease available.
