Koodo Reader manages and reads a local ebook library in formats including EPUB, PDF, MOBI and AZW3, plain text, FictionBook, comic archives, Markdown and DOCX. It supports highlights, notes and reading progress.

Library data can be synced or backed up through services such as WebDAV, Dropbox, OneDrive, Google Drive and others, and AI features work with a model you configure. macOS builds are published on GitHub releases alongside versions for other platforms.
