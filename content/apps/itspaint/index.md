ItsPaint brings a simple MS Paint–style canvas to the Mac, aimed mostly at quick screenshot markup: number steps, blur or pixelate sensitive areas, and drop the result into a bug report or document. It also works as a plain painting app when you start from an empty canvas.

The project states that the app does not request network access, and its drawing engine is published separately as a Swift package. Downloads come from GitHub releases, a Homebrew tap, or the Mac App Store; the README lists macOS 14 or later.
