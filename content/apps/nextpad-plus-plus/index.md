Nextpad++ brings the Notepad++ editor to the Mac by porting its original codebase rather than wrapping the Windows build in Wine. Familiar features carry over: syntax highlighting for dozens of languages, regular-expression search and find in files, macros, split views, a document map and a plugin system, now with Mac menus, shortcuts, file dialogs and dark mode.

The port is maintained separately from the Windows Notepad++ project. It requires macOS 11 or later, and the project distributes a signed, notarized universal DMG from its website, GitHub releases and Homebrew.
