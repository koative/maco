Nudge snaps windows to halves, quarters, thirds and two-thirds of the screen, maximizes or centers them, and moves them between displays. Every action has a keyboard shortcut that can be remapped, and windows can also be dragged to an edge or corner to snap.

It is a small, young project that runs from the menu bar and supports macOS 11 or later. It is unrelated to the macadmins Nudge update-reminder tool.
