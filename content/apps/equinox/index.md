Equinox turns a set of your own images into a native macOS dynamic wallpaper. You pick a wallpaper type, either solar position, time of day, or light and dark appearance, drop in the images, and export a file that macOS can use as a desktop picture.

It is a focused tool for one job rather than a wallpaper library. Builds are available from GitHub releases, and the project also links a Mac App Store listing.
