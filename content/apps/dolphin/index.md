Dolphin emulates GameCube and Wii systems on desktop computers. Its interface provides a game list, controller configuration, and settings for graphics and emulation.

Game software is supplied separately. Most original code is GPL-2.0-or-later, while the combined repository is GPLv3 compatible as explained in COPYING.
