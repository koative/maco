MacDirStat scans a drive or a chosen folder and lays out every file as a rectangle sized by the space it occupies, colored by file type and nested inside its folder. A sidebar lists folders from largest to smallest, an inspector breaks a selection down by type, and you can zoom, drill into a folder, or reveal a file in Finder to deal with it there.

The app never deletes or moves files itself and, according to the project, makes no network connections, so updates are manual downloads from GitHub releases. It requires macOS 15 or later. This is a young project: version 0.2.0 was released in October 2026.
