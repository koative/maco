xHistory collects the command history from the shells you use and shows it in a panel you can open from the menu bar, a keyboard shortcut or the command line. Commands are syntax highlighted, can be searched with regular expressions, pinned, and filled back into the terminal; the auto-fill feature needs Accessibility permission because it simulates typing.

It works with common shells without changing terminal settings, though a new shell session is needed after first launch. xHistory requires macOS 12 or later and is available as a disk image on GitHub or through the author's Homebrew tap. The latest release, 0.1.9, was published in June 2025.
