Pika is a compact colour picker for sampling foreground and background colours from the screen. Values can be copied as Hex, RGB, HSB, HSL, LAB, or OpenGL, and the app shows contrast information to help judge readability.

Keyboard shortcuts and a URL scheme make it quick to use from other tools. Downloads are offered on the project page and as GitHub release DMGs.
