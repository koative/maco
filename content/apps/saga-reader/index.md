Saga Reader gathers web content around keywords and interests you define, then uses a large language model to summarise what it found. A companion chat lets you ask questions about an article while reading, and data is stored on your own computer.

You need to configure either a cloud model provider or a local model on first use. The recent GitHub releases provide a macOS build for Apple silicon only, and releases have slowed since late 2025.
