Orca is a desktop workspace for supervising terminal-based coding agents such as Claude Code, Codex and OpenCode. Each agent gets an isolated git worktree, so one prompt can be sent to several agents and the results compared before merging the best one. Split terminals, diff annotation that feeds comments back to the agent, and GitHub and Linear browsing keep review in the same window.

Agents can also run on a remote machine over SSH, and a companion mobile app can follow and nudge them. macOS builds for Apple silicon and Intel are published on GitHub releases and linked from the official site.
