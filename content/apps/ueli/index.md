Ueli opens a search window from a global hotkey and finds applications, files, browser bookmarks and favourites as you type. Each result also has a menu of additional actions, and frequently used items can be pinned to the top as favourites.

Most of its features come from built-in extensions that can be switched on individually, including a calculator, currency and colour conversion, Base64 encoding, custom web searches, DeepL translation, system appearance switching and JetBrains Toolbox projects. It runs on macOS, Windows and Linux; the macOS builds are not signed or notarized, so the first launch has to be approved in System Settings. A Homebrew cask is also available.
