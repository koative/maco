Sequel Ace is a graphical client for MySQL and MariaDB. Browse tables, inspect structure and run SQL queries from a native Mac interface.

It continues the Sequel Pro lineage and supports common connection workflows, including SSH. Check the project documentation for database and authentication compatibility.
