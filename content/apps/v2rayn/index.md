v2rayN is a graphical front end for proxy cores such as Xray and sing-box. It keeps a list of servers and subscription links, lets you switch between them, and handles system proxy settings, custom routing rules and proxy chains so that selected traffic goes through the chosen node.

The project publishes macOS builds for both Intel and arm64 Macs on its GitHub releases page, alongside Linux packages. Its wiki explains which release file to pick and the minimum system versions. You need your own proxy servers or subscriptions; the app does not provide any.
