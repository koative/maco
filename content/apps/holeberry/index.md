Holeberry is a companion for people who already run Pi-hole. Its menu shows blocking status and query statistics, disables blocking for a set time or indefinitely, and can allow the domain of the tab open in Safari, Chromium or Firefox-based browsers.

It supports Pi-hole v6, with v5 described upstream as not fully tested, and can keep up to two instances in sync. The project requires macOS 14 or later and does nothing without a reachable Pi-hole server.
