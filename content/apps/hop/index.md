Hop gathers a set of small utilities behind a single menu bar icon: a Pomodoro timer and time tracker, a to-do list, keep-awake controls, a system monitor, clipboard history, a file converter, basic window arrangement, screenshots, text recognition and more. Each module can be turned on or off, and the enabled ones are spread across up to four tabs in the panel.

It suits people who would otherwise run several single-purpose menu bar apps. The project requires macOS 14 or later, states that it collects no analytics, and publishes its disk images, including a separate Intel build, on its GitHub releases page.
