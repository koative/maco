Ardour is a long-running open-source DAW for multitrack recording, non-destructive editing, MIDI sequencing and mixing, with support for audio plugins and control surfaces. It suits musicians, podcasters and engineers who want a full studio workflow without proprietary software.

Ready-to-run macOS builds are offered from the official site for a payment, while the source code stays freely available under the GPL; building it yourself is possible but unsupported by the project. The GitHub repository is the project's official mirror.
