Plonk gathers several small Mac utilities behind a single menu bar icon: screenshots with annotation and pinned crops, on-device OCR, an on-screen ruler, keep-awake timers, pointer highlighting, a shortcut inspector, snap zones and saved multi-monitor workspaces. Modules you do not need can be switched off.

It also ships a CLI and an MCP server so scripts and AI agents can drive the same tools locally. The project is young and maintained by one author; the README lists macOS 13 or newer on Apple silicon and warns that the automation interfaces may still change.
