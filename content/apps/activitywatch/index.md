ActivityWatch records the active application and window title, browser tabs through optional extensions, and whether you are away from the keyboard. A local web dashboard turns that history into timelines and category summaries you can use to see where working time actually goes.

Data is stored on the machine rather than sent to a hosted service, and the watcher-based design can be extended. Release pages provide macOS builds for Apple silicon and Intel. Window titles and URLs can be sensitive, so review what the watchers capture before leaving it running.
