Lepton is a desktop client for keeping code snippets in GitHub Gists. After you sign in with a GitHub account, it lists your gists, groups them by language or custom tags, and lets you create, edit and search snippets with syntax highlighting, including Markdown and Jupyter notebook previews.

Because everything is stored as ordinary gists, snippets stay available on GitHub and on any other machine where you run Lepton. Builds for Intel and Apple silicon Macs are published on the project's GitHub releases page.
