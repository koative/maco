MaCursor swaps the system cursors for your own artwork or downloadable themes, with a visual editor for tuning each cursor and hotkeys for switching. Themes can be assigned per app, and Windows, Linux and Mousecape cursor packs can be converted.

It also adds extras such as cursor trails, focus-follows-mouse, drawn mouse gestures that trigger actions, and Finder context menu commands. The project requires macOS 13 or later.
