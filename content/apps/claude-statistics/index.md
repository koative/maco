Claude Statistics reads the sessions of terminal coding agents, including Claude Code, OpenAI's Codex CLI and Gemini CLI, and turns them into usage, session and cost statistics. The menu bar shows each enabled provider side by side with its current quota consumption, coloured as limits approach.

A notch overlay lists running sessions, surfaces permission prompts you can allow or deny, and jumps back to the terminal tab a session lives in. Plugins add further subscription providers. Releases are DMGs that are not notarized, so the first launch needs to be approved manually.
