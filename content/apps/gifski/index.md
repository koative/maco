Gifski is a macOS interface for converting videos into animated GIFs. Adjust dimensions, frame rate, speed, cropping, looping, and quality to balance visual clarity against file size.

The current download is distributed through the Mac App Store. The upstream README also links older releases for earlier macOS versions.
