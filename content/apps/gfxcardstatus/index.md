gfxCardStatus is for the 15-, 16- and 17-inch MacBook Pro models from 2010 onwards that carry both an integrated and a discrete graphics processor. Its menu bar icon shows which one is active, lists the apps that are forcing the more power-hungry discrete GPU on, and lets you pin the machine to one GPU or return to automatic switching.

The last release, version 2.5, came out in December 2020 and remains available from GitHub and Homebrew. It is only useful on those dual-GPU laptops; other Macs have nothing for it to switch.
