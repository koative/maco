StrokeMouse recognises shapes you draw while holding a mouse button or a modifier key on the trackpad, plus experimental multi-finger touch gestures. Each gesture can trigger a keyboard shortcut, launch an app, manage windows, press media keys or run a shell command or AppleScript, either globally or only in a chosen app.

Gesture sets can be exported and imported as JSON. The project notes that releases use a self-signed identity rather than Apple notarisation, so Gatekeeper may ask for confirmation the first time.
