Capd is a personal capture library: a global shortcut, the share sheet, a drop target in the menu bar or notch, or a command-line tool saves the current page, a text selection, a link, a note or an image. It indexes page titles, readable article text and text recognized inside images, so captures can be found later through full-text search, a Raycast extension or a read-only MCP connection for AI assistants.

Everything stays in a local SQLite database without an account or telemetry, and on-device features tag captures and answer questions about the library with citations. Capd requires macOS 26 or later; notarized disk images are on GitHub releases, and the author also publishes a Homebrew tap. It is a young project with 0.0.x version numbers.
