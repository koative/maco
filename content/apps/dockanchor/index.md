On a Mac with several monitors, the Dock follows the pointer to whichever screen you push against at the bottom edge. DockAnchor stops that: pick the display the Dock belongs on and the app blocks it from moving anywhere else.

Profiles can switch the anchor display automatically depending on which monitors are connected, and a live diagram shows the current arrangement. It can run in the background from the menu bar and start at login. Signed builds are on GitHub releases, and the author also maintains a Homebrew tap.
