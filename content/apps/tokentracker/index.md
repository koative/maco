TokenTracker reads the local logs of AI coding tools, including Claude Code, Codex and Cursor, and turns them into a dashboard of token counts, estimated costs, models and activity over time. It needs no account or API keys; an optional sync that combines usage from several machines is off by default.

On the Mac it ships as a menu bar app with an embedded dashboard and desktop widgets for usage, an activity heatmap, top models and rate limits, plus a desktop pet that reacts to your coding activity. The same project offers a command-line tool and Windows and Linux apps. The macOS build is available from GitHub releases and a Homebrew tap.
