Tad opens tabular data files and database tables in a fast scrolling grid backed by an embedded DuckDB engine. A hierarchical pivot table lets you group, filter, aggregate, sort and reorder columns without writing SQL, and it can be launched from the command line with a file path.

Releases include macOS builds for Apple silicon and Intel. The latest release, 0.14.0, dates from June 2024.
