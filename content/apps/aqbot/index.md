AQBot is a chat client for many model providers at once: OpenAI, Claude, Gemini, DeepSeek, Qwen and any OpenAI-compatible endpoint, with model lists, per-model settings, branching conversations and side-by-side answers from several models. Saved roles, memory and knowledge bases sit alongside the chats.

It also works as an agent workbench. A conversation can switch into an agent mode that reads and edits files in a chosen folder with per-action approvals, and external coding agents can run through the Agent Client Protocol. A built-in gateway exposes the configured providers as a local API. Releases include macOS disk images for Apple silicon and Intel, plus Windows and Linux builds.
