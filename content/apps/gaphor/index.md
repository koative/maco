Gaphor is a modeling tool for UML and SysML. Elements placed on a diagram belong to an underlying UML 2 data model, so the same class or block can appear in several views and stay consistent, which makes it suitable for complete system models as well as quick sketches.

The interface is built with GTK, and models can also be scripted from Python or Jupyter notebooks. Releases provide separate macOS disk images for Apple silicon and Intel, alongside Windows and Linux builds. The project is Apache-2.0; its REUSE metadata lists a few files under other notices.
