WiFi Lens scans nearby networks on the 2.4, 5 and 6 GHz bands and draws channel occupancy charts and heatmaps, scores congestion with channel suggestions, and shows details such as PHY generation, channel width, roaming features and WPA3 support. It can also follow a single access point by signal strength, test roaming between access points, scan Bluetooth LE devices, and export charts as PNG or CSV. An optional local MCP server exposes scan data to AI clients.

This listing covers the open-source edition distributed through GitHub releases and a ShiinaLabs Homebrew tap. A separate paid WiFi Lens Pro on the Mac App Store adds monitoring, history and statistics that are not part of this repository.
