Pasty provides several ways to retrieve copied content, including a searchable central palette and a strip of cards. Pinboards and multi-selection help organize and paste frequently used material.

It is a newer project with evolving releases. Consult the release notes for the features available in the build you install rather than treating its roadmap as shipped functionality.
