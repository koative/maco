Whisky manages Wine prefixes, called bottles, through a Mac-style interface so Windows installers, launchers and games can run without command-line setup. Graphics translation layers, launcher compatibility settings and diagnostic reports are built in.

This entry follows the active community fork by frankea, which continued development after the original whisky-app/whisky repository was archived in April 2025; it is not affiliated with the original project. Upstream lists Apple silicon as required, and compatibility varies widely from title to title.
