Neon Vision Editor opens source files and Markdown documents in tabs for fast edits, with syntax highlighting, Markdown previews and project folder browsing. It deliberately stays small instead of growing into an IDE.

The same codebase also targets iPhone, iPad and Vision Pro. On the Mac it is available from GitHub releases, with App Store availability that upstream notes can vary; the project currently targets recent macOS versions.
