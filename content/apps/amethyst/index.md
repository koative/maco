Amethyst arranges application windows into tiling layouts, reducing the need to position each one manually. Keyboard commands make it practical to navigate and reorganize a desktop full of windows.

It uses macOS Accessibility APIs. The upstream documentation explains layout configuration and settings that make navigation between Spaces more predictable.
