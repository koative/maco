Claude Usage is a small menu bar app for people who use Claude Code. It shows how much of the current session and weekly limits has been used, along with pay-as-you-go credits and reset times, and can add a context readout to the Claude Code status line.

It reads the sign-in token Claude Code already keeps in the Keychain and has no backend of its own. It requires an existing Claude Code login and is only useful with that tool.
