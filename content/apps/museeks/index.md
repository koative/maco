Museeks imports a folder of music files and plays them from a straightforward track list, with playlists, queue management, shuffle and repeat, cover art and playback speed control. It supports common formats including MP3, AAC, FLAC, WAV and Ogg.

The project intentionally keeps its feature set small instead of competing with full library managers. GitHub releases include a universal macOS disk image; package-manager versions are community-maintained and may lag.
