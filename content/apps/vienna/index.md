Vienna is a feed reader for RSS, Atom and JSON Feed that follows a mail-client layout: scan headlines and summaries in a list, then read individual articles in a built-in browser view. Feeds can be fetched directly from websites.

It can also sync with services that implement the Open Reader API, such as FreshRSS or Inoreader. Releases and test builds are posted on GitHub, with a Homebrew cask as an alternative; check the release notes for the minimum macOS version of each line.
