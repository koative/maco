Claude Usage Tracker keeps an eye on how much of your Claude allowance is left. Its menu bar icon shows the current five-hour session and weekly usage, and the popover adds per-model breakdowns, reset times, API console spending and charts of past usage. Several accounts can be tracked side by side as separate profiles, and newer versions can also follow OpenAI Codex limits.

For Claude Code users it can switch CLI credentials with the active profile and feed a configurable status line in the terminal. Credentials are stored in the macOS Keychain; the app sends only a minimal anonymous version heartbeat. Builds are published on GitHub releases.
