VirtualBox creates and runs virtual machines, so another operating system can run in a window alongside macOS. Machines are configured with virtual disks, networking, shared folders and snapshots, and can be exported and imported in common appliance formats or controlled from the command line.

The base package is GPL version 3, with some interface headers also offered under the CDDL; the separate Extension Pack uses Oracle's own licence and is not part of this listing. Oracle publishes macOS installers for both Apple silicon and Intel hosts.
