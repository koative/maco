CodeBurn reads the session files that Claude Code, Codex, Cursor and dozens of other coding tools already write to disk, prices every token, and splits the spending by tool, model, project, git branch and kind of task. There is no account to create; the numbers come from files on your machine.

On the Mac it comes as a desktop app with drill-down from totals to individual sessions, a menu bar item showing the day's spend, and an optional screen-edge dock of quota rings per provider. The same engine also runs as a terminal command and a browser dashboard, and an optimize command suggests configuration changes that waste fewer tokens. The project states that all of it, including the desktop and menu bar apps, is MIT licensed in this repository.
