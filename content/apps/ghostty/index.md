Ghostty combines a native Mac interface with a terminal renderer built for demanding command-line work. It supports tabs and splits so several shells can stay visible together.

Its configuration file controls fonts, colors, shortcuts, and terminal behavior. This entry covers the desktop application, rather than the embeddable libghostty library.
