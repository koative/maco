ElectronMail wraps the Proton Mail web interface in a desktop app and adds features the browser version lacks: several accounts side by side, an encrypted local store for offline reading, full-text search across message bodies and scriptable filtering.

It is a community project, not made by Proton, and it handles your Proton credentials, so review its documentation before signing in. macOS disk images for Intel and Apple silicon are attached to each GitHub release.
