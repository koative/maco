Claude God shows progress bars for Claude's session, weekly and per-model limits in the menu bar, with countdowns to each reset and a burn-rate estimate of when you will run out. The icon can change colour as limits get tight, and a notification can tell you when a quota resets.

For Claude Code users it also reads local session files to build daily, weekly and monthly cost breakdowns by project and model, a usage trend chart, a daily budget target and CSV export. It picks up an existing Claude Code login automatically. Builds are published as GitHub releases.
