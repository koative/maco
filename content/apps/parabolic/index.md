Parabolic puts a graphical interface on yt-dlp: paste a link from YouTube or one of the many other sites yt-dlp supports, pick a format such as MP4, WebM, MP3, Opus, FLAC or WAV, and run several downloads side by side, with metadata and subtitles saved alongside the media.

Nickvision builds it for Linux, Windows and macOS; the Mac versions are zipped downloads for Apple Silicon and Intel on GitHub releases. The project reminds users that videos on many sites are protected by copyright and that they are responsible for how they use the tool.
