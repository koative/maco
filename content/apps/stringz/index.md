Stringz opens an Xcode project and gathers its localizable content, including `.strings` files, storyboards, XIBs and `Info.plist` entries, into one table with a column per language. Missing translations are highlighted and duplicate values flagged, which makes it easier to see what still needs work before a release.

It can also add new languages and localize files that were not yet set up for translation. The latest release, 0.7.5, dates from December 2022 and is available from the GitHub releases page or as the `stringz` Homebrew cask. The repository moved from its original `mohakapt/Stringz` address, which now redirects here.
