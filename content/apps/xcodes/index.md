Xcodes lists available Xcode releases, downloads and installs the one you pick, and makes a version active with `xcode-select`. It can also install simulator platforms and runtimes and shows release notes and SDK details from Xcode Releases.

Downloading Xcode requires an Apple ID. The project, now maintained under XcodesOrg, publishes signed and notarized builds on GitHub and through Homebrew, and has a separate command-line tool for scripted use.
