Switzy stores Git profiles, each with a name, email address and SSH key, and switches the active one from the menu bar so commits and pushes use the right account. It edits Git configuration and SSH key settings for you instead of requiring manual changes to config files.

Notarized disk images are published on GitHub releases and through the developer's Homebrew tap.
