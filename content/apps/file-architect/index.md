File Architect turns a plain-text outline into real folders and files. You write the tree you want, one name per line with indentation for nesting, and the app creates it in a chosen destination, which is handy for setting up project skeletons, client folders or recurring archive layouts. Tabs keep several structures open at once.

It is a Tauri desktop app for macOS and Windows, with Apple silicon and Intel DMGs on GitHub. The source is MIT-licensed, while the official website sells licences for the packaged app after a seven-day trial.
