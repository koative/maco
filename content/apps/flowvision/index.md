FlowVision lays out the images in a folder as an adaptive waterfall grid and opens them full size with a double click. It also plays videos, handles very large directories, supports HDR displays, and offers Finder-like file operations.

Navigation leans on right-button mouse gestures and keyboard shortcuts to jump to the next or previous folder that contains media. The app works offline; the project lists macOS 11 or later.
