Thor does one thing: it lets you bind a global keyboard shortcut to each application you use often, then opens that app whenever you press the combination. It suits people who prefer a fixed set of hotkeys over typing an app's name into a launcher.

The latest release is 1.5.16 from September 2024. It is available from GitHub releases, a Homebrew cask and the Mac App Store.
