UTM provides a graphical way to create and run virtual machines on macOS. Depending on the guest and hardware, it uses virtualization or emulation to run other operating systems.

Guest operating systems and their licenses are obtained separately. The project offers a direct Mac download alongside an optional App Store distribution.
