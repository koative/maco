SaneHosts builds /etc/hosts entries from profiles, offering preset protection levels and a library of community blocklists that can be merged and deduplicated. Activating a profile goes through the macOS authorization prompt and flushes the DNS cache; earlier versions of each profile are kept as backups.

The direct download starts a 14-day trial and continues with a one-time purchase. The project describes limited anonymous product events alongside optional network features. Its source is published under PolyForm Shield, so this entry is classified as source available.
