SmartPush is a small Mac tool for iOS developers who need to check that push notifications arrive. Pick a push certificate from a list or drop in a certificate file, paste a device token, write or pick a JSON payload, select the sandbox or production environment, and send.

It started as a modified version of the older PushMeBaby utility and its documentation is mainly in Chinese. The latest release, 3.4, was published in February 2024 and is available from GitHub releases.
