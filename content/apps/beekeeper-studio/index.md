Beekeeper Studio Community connects to supported databases for writing queries and browsing tables. Its interface groups connections, saved work, and query results in a desktop workspace.

This entry covers the GPL Community edition. The repository also contains separately licensed commercial code, and paid editions add features beyond Community.
