Xit is a graphical Git client that started as a rewrite of GitX. A sidebar lists branches, remotes, tags, submodules and stashes; the history view draws the commit graph and can be searched by author, message or hash; and file lists show diffs, blame with colour-coded change groups, plain text or Quick Look previews for both the working tree and past commits.

The author still describes it as beta software working toward a 1.0 milestone, and every GitHub release is marked as a pre-release. The latest, 1.0b18 from April 2026, requires macOS 26.
