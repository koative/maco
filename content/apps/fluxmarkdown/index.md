FluxMarkdown adds a Quick Look preview for Markdown files, so pressing Space in Finder shows rendered GitHub Flavored Markdown instead of raw text. Mermaid diagrams, KaTeX math, charts and a generated table of contents are rendered inside the preview.

It installs as a regular app that carries the Quick Look extension, from the DMG releases or the project's Homebrew tap. The code is GPL-3.0, with a separate commercial license offered for closed-source use.
