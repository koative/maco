qBittorrent manages torrent downloads through a desktop interface. It provides controls for queues, priorities, and transfer behavior.

The source is GPL-2.0-or-later with an OpenSSL exception; distributed binaries use GPL-3.0-or-later because of included assets. The upstream download page provides the macOS build.
