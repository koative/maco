PeekX adds folder support to Quick Look: select a folder in Finder, press Space, and the preview summarises its contents with the number of files, total size and a breakdown by file type. Version 1.1 also previews Markdown files.

The download is a small host app that registers the extension the first time it is opened and then quits. The README lists macOS 14 Sonoma or later. The latest release, 1.1, dates from November 2025.
