Bdash is aimed at quick analysis rather than database administration. Write and save queries against MySQL, PostgreSQL or Redshift, SQLite, BigQuery, Treasure Data or Athena, then turn a result into a simple chart or share it as a gist.

The Electron app ships universal macOS builds on GitHub. It does not try to replace schema designers or full admin tools such as DBeaver; it keeps a focused query history for repeated look-ups.
