Claude Usage Monitor shows how much of your Claude.ai plan allowance you have used, with a colour-coded menu bar icon, progress bars for different limits and a countdown to the next reset. It signs in through a Claude.ai login window instead of an API key.

This is an unofficial tool that reads the same internal endpoints the Claude website uses, so changes on Anthropic's side can break it until it is updated.
