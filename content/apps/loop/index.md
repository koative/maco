Hold a trigger key to reveal a radial menu, then steer toward the window layout you want. Loop provides a visual way to move and resize windows without memorizing a separate shortcut for every position.

Customize the menu colors and behavior to suit your desktop. The upstream project provides a downloadable macOS application and documents its current system requirements.
