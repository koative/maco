Sentinel puts a few Gatekeeper tasks behind buttons and a drop zone. Drop an app on its window to remove the quarantine attribute (and optionally launch it), or to replace its signature with an ad hoc one; a Finder extension adds unquarantining to the right-click menu, and Gatekeeper itself can be switched on or off from the main window.

The author has put the project on hold since late 2025, and the latest release is 3.1.4 from November 2025. It comes from the developer of Pearcleaner and, like it, adds the Commons Clause to Apache 2.0, so this listing is classified as source available. Use it with care: it deliberately weakens a macOS security check for the apps you choose.
