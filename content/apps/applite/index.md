Applite puts a graphical catalog on top of Homebrew Cask, so Mac software that is not sold through the App Store can be found, installed, updated and uninstalled with a click. It can manage its own Homebrew installation, which means newcomers do not need Terminal or the Command Line Tools first.

It deliberately covers casks only, not command-line formulae or services, and can import and export Brewfiles to set up another Mac. Existing Homebrew users can point it at their current installation instead.
