Table Habit tracks small daily habits in a grid, rates each one with its own scoring system and charts how a routine develops over time. Data is stored locally with JSON import and export, and can be synced between devices through any WebDAV server; no account is needed.

The Flutter app runs on Android, iOS, Windows and Linux too. On the Mac it is available from the Mac App Store or as a disk image on the project's GitHub releases.
