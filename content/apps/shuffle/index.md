Shuffle is a file manager for people who find Finder limiting. It offers tabs, split panes with independent history, a fuzzy command palette, an optional shell-like command bar, and themes, with GPU-rendered lists intended to stay fast in very large folders.

It is written in Rust with the GPUI framework and is still early, with 0.x releases on GitHub.
