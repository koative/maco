Pulse keeps a slim rail on the edge of the screen with one ring per service, covering Claude Code, Codex, Cursor, GitHub Copilot and many other AI coding tools. Each ring fills as a usage window is consumed, and pointing at it shows every limit, its reset time and a forecast of when your current pace would run out.

It signs in with the credentials those tools already store and checks only the services you enable, without a Pulse account or server. The rail can sit on any edge, fold away when idle, or live in the menu bar instead. Builds are not signed with an Apple Developer certificate, so macOS asks for confirmation on first launch. Not to be confused with other apps named Pulse.
