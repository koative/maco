FlowDown is a chat front end for language models on Apple devices. It can use Apple Intelligence where available, download and run MLX models locally, or connect to any OpenAI-compatible service, including self-hosted servers such as Ollama or LM Studio. Conversations render Markdown with syntax highlighting and accept images, audio and file attachments.

Other features include web search for the model, reusable prompt templates, and syncing of conversations and settings through your own iCloud account; the developers state that they collect no usage data. The Mac version is a paid App Store download, and the project also publishes macOS builds on GitHub, which the `flowdown` Homebrew cask installs.
