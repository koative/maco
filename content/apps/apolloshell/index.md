ApolloShell brings the look of Linux desktop shells such as Caelestia to macOS 26. It adds panels to the screen edges: a sidebar with its own dock and status blocks, a launcher, a dashboard with weather, calendar and media, and a control centre, all themed from a single CSS file and arranged in its settings app.

It is an early release that relies on private macOS interfaces, so system updates may break parts of it. It complements Finder and the window manager rather than replacing them.
