ClashBar manages a mihomo (Clash-compatible) proxy core from the menu bar: import and update configuration profiles, switch nodes and test latency, choose rule, global or direct mode, and toggle the system proxy. It also shows live traffic, connections, memory use and filtered logs.

The interface is available in Chinese and English, and releases include builds with or without the bundled core. Only one Clash-family client should control the system proxy at a time, and the project requires macOS 13 or later.
