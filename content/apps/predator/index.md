Predator is a macOS screensaver that shows the current time in segmented red glyphs modelled on the countdown display from the Predator films. The project's README explains how to read the digits, and the options cover the clock colour, a 12- or 24-hour format, and hiding extra lines for a look closer to the film prop.

It installs as a `.saver` bundle from the GitHub releases page and requires macOS 11.5 or newer. Version 1.0.7 was released in May 2025.
