ElectroCRUD connects to MySQL or MariaDB, PostgreSQL, SQLite and Microsoft SQL Server and turns tables into browsable views for creating, reading, updating and deleting rows without writing SQL. Version 3 adds documentation fields for tables and columns, tags, and policies for marking sensitive data.

The latest stable release is v3.0.19 from June 2023, with an Intel macOS DMG on GitHub releases and in the `electrocrud` Homebrew cask; later development builds are marked as pre-releases.
