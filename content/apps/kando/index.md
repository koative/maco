Kando opens a circular menu around the mouse pointer when you press a global shortcut. Each slice can launch an application, open a file or URL, run a command, type text or trigger a keyboard shortcut, and slices can nest into submenus so a flick of the mouse reaches a deep action. It also works with a stylus, touch, a game controller or the keyboard alone.

Menus, themes and sounds are edited in a built-in settings window. Kando is an Electron app for macOS, Windows and Linux; its source code is MIT-licensed while bundled icons, themes and other assets carry their own terms, recorded file by file under the REUSE specification.
