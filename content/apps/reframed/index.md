Reframed combines a screen recorder with a timeline editor for polished demos and tutorials. It captures the whole screen, a single window, a region or a USB-connected iOS device, along with system audio, microphone and an optional webcam. Cursor position and clicks are tracked separately, so the editor can generate zoom-and-pan keyframes that follow the pointer, which you can then adjust by hand.

The editor also trims each audio and video track, cleans up microphone noise with RNNoise, adds backgrounds and padding, and produces on-device captions. The project presents itself as an open alternative to Screen Studio. DMG builds are on GitHub releases and through the author's Homebrew tap; the README states macOS 15 or later.
