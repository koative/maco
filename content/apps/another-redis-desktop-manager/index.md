Another Redis Desktop Manager is a graphical client for Redis. It lists keys with their types, lets you inspect and edit values, and includes a console for running commands directly.

Connections can go through SSH tunnels and target clusters or Sentinel setups. Apple silicon and Intel DMGs are published with each GitHub release.
