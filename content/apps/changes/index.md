Changes is a graphical Git client covering everyday work: stage by hunk, commit and amend, manage branches, tags and stashes, push and pull, and search history by message, change, author or revision range. Commit message snippets help keep messages consistent.

Optional commit-message and stash-summary generation uses Apple Intelligence. Version 2 requires macOS 26; older 1.x releases, previously named Tempo, remain available for macOS 14.6 and later.
